# Image Analysis Software

This repository contains the MATLAB code accompanying the published image analysis method.

## Getting Started

The main script is:

`MAIN.m`

All necessary information regarding the use of the software is provided directly within `MAIN.m`. The script is extensively commented and organized into sections, with instructions and explanations provided step by step.

Please follow the sections of `MAIN.m` in order. In particular, the **OPTIONS (USER INPUT)** section contains the parameters that can be adjusted by the user before running the analysis.

## Requirements

The software is intended to be run in MATLAB. Required functions, parameters, and analysis steps are described within the script.

## Usage

1. Download or clone this repository.
2. Open `MAIN.m` in MATLAB.
3. Read the instructions provided in the script, section by section.
4. Adjust the parameters in **OPTIONS (USER INPUT)** as required for your data.
5. Run the script according to the instructions provided in `MAIN.m`.

For detailed information about individual processing and analysis steps, please refer to the comments and explanations included directly in the source code.
